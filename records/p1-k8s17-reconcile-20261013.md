실행 보조는 허용된 고정 파일 교체만 수행하는 코드이며 해당 collector.py 원본과 명령·rc·시각을 그대로 편입한다. `*-independent`는 변경 코드와 분리된 읽기 수집을 뜻하며 **사람의 독립 리뷰를 뜻하지 않는다**. 자체 검증을 원 개발 코드의 독립 승인으로 표기하지 않는다. API 자료는 전체 응답 대신 선택 필드와 응답 SHA를 남긴 수집 결과다. SHA 일치는 현재 증적 무결성 범위이며 Runtime 기능 성공이나 최종 인수의 대체 근거가 아니다.

검토용 코드는 기록이다. `collector.py`·dispatch.py를 재실행하는 안내가 아니다. 로컬 읽기 검증만 `python3 verify_results.py <이 수집회차 경로>`로 수행할 수 있다. 인수를 위해 새 운영 시험이나 중복 코드 리뷰를 자동 추가하지 않는다.
